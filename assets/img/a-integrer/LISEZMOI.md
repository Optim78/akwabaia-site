# Photos à intégrer dans les vidéos publicitaires

Dépose ici les photos à intégrer. Nomme chaque fichier d'après son contenu, par exemple :

- `moi-1.jpg`, `moi-2.jpg` : tes photos personnelles
- `client-produit-1.jpg`, `client-boutique-1.jpg` : produits ou commerces de clients (pub 5 000 FCFA)
- `avant-1.jpg` / `apres-1.jpg` : un exemple avant / après
- `linkedin-1.png`, `lettre-1.png` : vrais exemples (coordonnées masquées)
- `temoignage-4.png`, ... : nouveaux témoignages
